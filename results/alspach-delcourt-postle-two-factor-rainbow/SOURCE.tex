Recall that a matching $M$ of a (not necessarily properly) edge colored hypergraph $G$ is \emph{rainbow} if every edge of $M$ is colored differently and a rainbow matching is \emph{full} if every color of the coloring appears on some edge of $M$.

\begin{conj}[Alspach~\cite{A88}]\label{conj:Alspach}
If $G$ is a simple $2d$-regular graph that is edge colored such that each color class is a $2$-factor, then $G$ has a full rainbow matching.
\end{conj}

% Standard terminology used in the source: a 2-factor is a spanning 2-regular subgraph.
