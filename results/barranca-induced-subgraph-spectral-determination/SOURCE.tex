\textbf{Definition 2.1.1.} Let $\mathcal{G}$ be a set of graphs. We define
$\mathcal{G}$ to be \emph{recognizable by spectrum} (RS) if the spectrum of
a graph $H$ determines whether $H$ contains any graph $G\in\mathcal{G}$
as an induced subgraph. If $\mathcal{G}$ is a singleton set containing
only the graph $G$, we will say $G$ is RS.

\textbf{Conjecture 2.1.2.} The five graphs $K_1$, $2K_1$, $K_2$, $K_3$,
and $P_3$ are the only RS graphs.
